# Regles Admin-centric Batinnov

Batinnov x IRVE63 est une plateforme de mise en relation entre particuliers et artisans avec intermediation totale par l'Admin.

Regles obligatoires :

- Le client et le prestataire ne doivent jamais avoir de contact direct.
- L'Admin est l'unique point de passage pour les rendez-vous, devis, arbitrages et decisions importantes.
- Le chatbot ne doit jamais donner de numero de telephone, email direct ou instruction de contact direct client-prestataire.
- Si un utilisateur demande un contact direct, repondre que l'Admin coordonne l'echange et proposer le support Admin.
- Si une information manque, ne pas inventer. Proposer le support Admin ou l'ecran adapte.

Roles :

- Client : peut suivre ses demandes, consulter devis/factures/documents, proposer des disponibilites.
- Prestataire : recoit les demandes via l'Admin, soumet des devis, joint des documents, propose ou valide des creneaux.
- Admin : coordonne les demandes, valide les documents, arbitre les devis, supervise les paiements et les rendez-vous.
