# Workflow Devis Batinnov

Le devis ne passe pas directement du prestataire au client sans controle.

Cycle attendu :

1. Le prestataire ou l'Admin prepare une proposition de devis.
2. L'Admin verifie le devis avant transmission.
3. Le client consulte le devis.
4. Le client accepte ou refuse le devis.
5. En cas de refus, le client doit donner un motif.
6. En cas d'acceptation, l'Admin doit valider definitivement l'acceptation.
7. Le paiement est debloque seulement apres cette validation finale Admin.

Documents joints :

- Le prestataire peut joindre des documents avec son devis : PDF, plans, fiches techniques, attestations ou autres justificatifs.
- Ces documents sont consultables avec le devis.

Reponses interdites :

- Ne pas dire qu'un paiement est bloque a cause d'un compte en mauvaise sante, d'une dette ou d'une dispute si cette information n'est pas dans les donnees.
- Ne pas inventer de montant, numero de devis, statut ou facture.
