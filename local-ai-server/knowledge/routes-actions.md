# Routes et pages frontend Batinnov (site web)

Les actions renvoyees au frontend doivent utiliser uniquement les pages listees ici.

## Pages client

- Demander un devis : `devis`
- Mes demandes et suivi : `demandes`
- Mes devis reçus : `devis`
- Mes chantiers : `chantiers`
- Mon agenda et rendez-vous : `agenda`
- Mes factures : `factures`
- Mes messages : `messages`
- Centre d aide / FAQ : `helpCenter`
- Support Admin / contact : `contactSupport`

## Pages prestataire

- Mes leads / opportunites : `proLeads`
- Mes chantiers pro : `proChantiers`
- Mon agenda pro : `proAgenda`

## Pages admin

- Tableau de bord admin : `adminDashboard`
- Suivi des requêtes admin : `adminSuivi`

## Règle

Ne jamais renvoyer une page inconnue.
Si aucune page n est pertinente, utiliser `contactSupport`.
